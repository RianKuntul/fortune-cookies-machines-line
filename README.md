One fortune-cookie slip written for a machine: a single line with a sting,
cracked open by an AI agent.

## Run

```
node main.ts
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The entry is one line, 1–200 characters, with no trailing newline.
